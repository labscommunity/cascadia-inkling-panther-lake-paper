# Runtime architecture and implementation anchors

All links in this ledger pin Cascadia commit **3189a189fe3428f5a6315a7eb67b13148ec314e2**. Code inspection establishes what a path implements, not that every option was enabled in every experiment. Per-experiment overrides and retained measurements establish actual use.

| Mechanism | Pinned implementation | Interpretation |
|---|---|---|
| Six consecutive layers on each of eleven roles | [Inkling stage partition](https://github.com/labscommunity/cascadia/blob/3189a189fe3428f5a6315a7eb67b13148ec314e2/crates/cascadia-engine-sparse-moe/src/inkling/stage.rs#L26) | 66 layers divided over 11 roles; stage 0 handles embedding and stage 10 the output head. |
| Attention state and CPU/GPU boundary | [Attention implementation](https://github.com/labscommunity/cascadia/blob/3189a189fe3428f5a6315a7eb67b13148ec314e2/crates/cascadia-engine-sparse-moe/src/inkling/attn.rs#L546) | OpenVINO projections feed CPU attention/state work. Row-parallel attention begins at `attend_rows_parallel`; GPU activity does not imply all attention arithmetic runs on GPU. |
| Relative-position bias and short convolution | [Relative bias](https://github.com/labscommunity/cascadia/blob/3189a189fe3428f5a6315a7eb67b13148ec314e2/crates/cascadia-engine-sparse-moe/src/inkling/relpos.rs), [convolution](https://github.com/labscommunity/cascadia/blob/3189a189fe3428f5a6315a7eb67b13148ec314e2/crates/cascadia-engine-sparse-moe/src/inkling/conv.rs) | Inkling is not a RoPE decoder; speculative rewind must restore convolution history as well as KV state. |
| Fused expert setup, runtime options and scaling | [OpenVINO MoE](https://github.com/labscommunity/cascadia/blob/3189a189fe3428f5a6315a7eb67b13148ec314e2/crates/cascadia-engine-sparse-moe/src/inkling/ov_moe.rs) | Compressed expert execution, shape buckets, decode/prefill path selection and numerical guards; environment settings differ by experiment. |
| Dense backend and head | [Dense path](https://github.com/labscommunity/cascadia/blob/3189a189fe3428f5a6315a7eb67b13148ec314e2/crates/cascadia-engine-sparse-moe/src/inkling/ov_dense.rs), [head](https://github.com/labscommunity/cascadia/blob/3189a189fe3428f5a6315a7eb67b13148ec314e2/crates/cascadia-engine-sparse-moe/src/inkling/ov_head.rs) | Distinguish three compressed dense projections from the later all-active fused-expert mapping; head runs on the final role. |
| Forward residual wire dtype | [`hidden_to_tensor`](https://github.com/labscommunity/cascadia/blob/3189a189fe3428f5a6315a7eb67b13148ec314e2/crates/cascadia-engine-sparse-moe/src/dist.rs#L312) and [`send_stream_decode`](https://github.com/labscommunity/cascadia/blob/3189a189fe3428f5a6315a7eb67b13148ec314e2/crates/cascadia-engine-sparse-moe/src/dist.rs#L1640) | Serializes each f32 as four little-endian bytes and declares `DType::F32`; one width-6144 row is 24,576 payload bytes before protocol metadata. A hypothetical FP16 expert-parallel traffic estimate is not the current pipeline wire format. |
| Direct sampled-token reply | [`send_tokens_reply`](https://github.com/labscommunity/cascadia/blob/3189a189fe3428f5a6315a7eb67b13148ec314e2/crates/cascadia-engine-sparse-moe/src/engine.rs#L6874) | Final role returns IDs to ingress through the direct link when configured; next-token generation is a closed loop. |
| Speculative stream output | [`spec_emit`](https://github.com/labscommunity/cascadia/blob/3189a189fe3428f5a6315a7eb67b13148ec314e2/crates/cascadia-engine-sparse-moe/src/engine.rs#L7198) | Constructs one chunk per accepted/emitted target token, explicitly sets `n_tokens=Some(1)` and a one-element ID vector; terminal marker has count zero. |
| Ordinary stream output | [Stream chunk emission](https://github.com/labscommunity/cascadia/blob/3189a189fe3428f5a6315a7eb67b13148ec314e2/crates/cascadia-engine-sparse-moe/src/engine.rs#L7587) | Same one-token contract in the inspected ordinary multi-stream path. |
| API token accounting and SSE | [`chunk_token_count`](https://github.com/labscommunity/cascadia/blob/3189a189fe3428f5a6315a7eb67b13148ec314e2/crates/cascadia-api/src/lib.rs#L60), [chat streaming](https://github.com/labscommunity/cascadia/blob/3189a189fe3428f5a6315a7eb67b13148ec314e2/crates/cascadia-api/src/lib.rs#L2936) | Explicit engine counts feed server statistics; a structural token can yield an empty text string while its delta object and token count remain present. |
| Historical measurement definitions | [Frozen harness](evidence/source/autolab/bench/lab.py), `stream`, `gate`, `gate_multi`, `run_phase` | Counts nonfinal nonempty delta objects; computes phase tokens/time and sum of per-request decode rates separately; implements weak prefix gates. |
| Profile deduplication and clock mapping | [Frozen telemetry analysis](evidence/source/autolab/bench/telemetry_analysis.py) | Preserves physical box and role separately; timestamps derive from receipt age; diagnostic probes are excluded as timing windows. |
| State capture | [Capture implementation](https://github.com/labscommunity/cascadia/blob/3189a189fe3428f5a6315a7eb67b13148ec314e2/crates/cascadia-engine-sparse-moe/src/inkling/capture.rs) | Corrected FP32 format, budget and error handling; finite residual capture is required before offline rescore. |

The [scrubbed architecture notes](evidence/source/docs/architectures/inkling.md) and [fleet defaults](evidence/source/deploy/inkling-fleet/fleet.env) are included locally. Full Rust files remain in the source repository, rather than being duplicated as an unmaintained second implementation.
